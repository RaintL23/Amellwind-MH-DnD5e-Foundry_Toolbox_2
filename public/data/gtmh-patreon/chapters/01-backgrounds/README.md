# Backgrounds

Curated notes for GTMH Patreon faction backgrounds.

## Runtime

- Parser: `scripts/gtmh/backgrounds.mjs` reads `gtmh-patreon-chapter1.md`
- Overlay key: `background[]` in `public/data/gtmh-patreon/supplement.json`
- Rebuild: `pnpm build:gtmh-supplement`
- Merge: local-wins by name; GitHub fills uncovered names only
